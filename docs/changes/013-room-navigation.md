# 013 — 방 바로가기 자동 걷기와 간결한 지도 조작

상태: 완료 (구현·자동 검증 범위; 현재 리비전 최종 수용 게이트는 최종 검증 기록에서 관리)

## 변경 이유와 범위

복도·팀 방·대표실과 임시 방의 바로가기를 눌러도 안내만 바뀌므로, 선택한 방 안까지 대표가 기존 벽 안전 경로로 걸어가게 한다. 층 진입 뒤 직접 둘러보기를 기본으로 제공하고 시작·끝내기 버튼을 없앤다. 설명 패널을 줄이고 미니맵은 화면 모서리에 고정한다.

모든 구역 바로가기와 지도 문 버튼은 같은 이동 목적지 수명주기를 사용한다. 새 목적지는 이전 목적지를 바꾸며, 수동 이동·일시정지·Esc·결재·방문 창·층 전환은 이동을 취소한다. 경로를 찾지 못하면 오류 상태를 표시한다. 직원 살펴보기, 엘리베이터·층 선택, 로비 복귀, 전체 보기 유지, 키보드와 감소된 모션은 보존한다.

서버, 공유 계약, 의존성, 기본 디자인 기준과 배포는 변경하지 않는다. 새 설정이나 별도 경로 계산기는 추가하지 않는다.

## 구현·검증 순서

1. [Office](../../web/src/Office.tsx)의 모든 방 이동 호출자와 이동 생명주기를 확인한다.
2. 모든 실제 부서 바로가기·지도 문 이동, 재지정·수동 취소·경로 실패를 검증하는 회귀 검사를 먼저 추가한다.
3. 기존 `findVisitorPath`와 목적지 상태를 재사용해 모든 방 도착, 기본 둘러보기와 고정형 소형 지도·조작부를 구현한다.
4. [사용자 흐름](../4-USERFLOW.md)과 [진행 보고·사무실 요구사항](../requirements/progress-office.md)을 결과에 맞춘다.
5. 대상 테스트, 전체 테스트, typecheck, build를 실행한다. R1 Impeccable/E2E 리뷰는 통과했고, 코드 리뷰의 필수 보강은 반영했다. R2에서 집중 테스트 4개, 대상 테스트 90개(5개 파일), 전체 테스트 212개(18개 파일), typecheck, build, `git diff --check`가 모두 통과했다. Vitest는 Lobby 층 메뉴와 App 오래된 엘리베이터 콜백 테스트에서 기존 React `act(...)` 경고를 출력했다. 구현 리프는 실제 브라우저 검수를 수행하지 않는다. 현재 리비전의 최종 독립 리뷰와 데스크톱·모바일 브라우저 검수 결과는 루트의 [최종 검증 기록](../../.omx/artifacts/room-navigation/final-result.md)에서 관리한다.

## 완료 검증

역할 데이터에 정의된 모든 방으로 방 안에 도착하고, 상단 바로가기·문·방 제목 버튼의 재지정과 이동 중 수동 이동·일시정지·Esc 취소, 일시정지 중 새 목적지 선택, 경로 오류를 자동 검사한다. 형제 컨트롤 포커스에서의 Escape 취소, 수정·조합·편집 입력에서의 Escape 소유권, 직원 상세 뒤 엘리베이터를 화면 조작으로 연 경우 지도 포커스 복귀도 검사한다. 직원·엘리베이터 이동과 층 전환, 일반·전체 보기 유지의 기존 검사를 보존한다. 현재 리비전 최종 제품 수용 여부와 검수 판정은 루트 최종 검증 기록을 따른다.
