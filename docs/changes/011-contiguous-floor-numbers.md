# 표시 층 연속 번호

상태: 완료

숨긴 층 때문에 4·3·1층처럼 빈 번호가 남는 문제를 해결한다. [층 숨김 요구사항](../requirements/progress-office.md#building-층-숨김복원)을 변경하여 표시 프로젝트만 경로 정렬 후 1층부터 번호를 매긴다. 로비·엘리베이터 공용 계산만 수정하며 저장 데이터·이동·전체 보기 상태는 변경하지 않는다. 변경 007의 번호 고정 정책을 대체한다.

검증: 숨김·복원·모두 숨김을 포함한 대상 4개 파일 36개 테스트 통과. 타입 검사·프로덕션 빌드 통과. 실행 중 컨테이너 갱신과 실제 브라우저 확인은 수행하지 않았다.
