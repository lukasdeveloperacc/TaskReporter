# 체크인 질문 한국어 간소화

상태: 완료 (로컬 검증, 배포 전)

새 체크인 질문을 한국어 한두 줄로 줄이고 해당하는 정체·누락 필드·미완료 TODO 안내만 넣는다. 실제 메타데이터 확인·확인 불가 이유·추측 금지, 최신 TODO 확인·실제 끝난 항목만 완료 보고하는 지침을 보존한다. report/get_run 응답은 checks·asks를 state보다 앞에 조립한다. 이는 가독성 목적이며 JSON 키 순서를 동작 계약으로 삼지 않는다.

[결재·체크인 요구사항](../requirements/decisions-integration.md#체크인-문구와-표시-순서)에 반영한다. 저장된 질문·생성 조건·쿨다운·DB·UI·외부 스킬·이미지 배포는 변경하지 않는다.

검증 기준: 한국어 질문·조건부 안내·기존 pending 질문 보존·응답 순서·전체 테스트·타입 검사·빌드.

검증 결과: 전체 테스트 18개 파일·216개 통과, npm run typecheck·npm run build·npm run golden·git diff --check 통과. MCP 통합 테스트로 정체/누락 조건별 한국어 안내·불필요한 안내 생략·text/structuredContent 표시 순서를 확인했다. 기존 미완료 TODO/최신 조회·pending 유지 테스트도 통과했다. 실제 호스트·컨테이너 갱신은 미검증이다.

독립 리뷰: 코드 지적 없음. 생성 당시 누락 필드가 있을 때만 안내하는 정책과 맞지 않던 기존 요구사항 한 문장을 정정했다. 리뷰어도 app/store 36개 테스트와 typecheck 통과를 확인했다.
