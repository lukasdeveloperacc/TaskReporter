# 005 — 중앙 업무 보고와 연속 탐색

상태: 완료(구현·자동 검증 범위). 중앙 보고 모달과 연속 탐색의 자동 검증을 마쳤다. 실제 브라우저·최종 독립 리뷰 판정은 별도 실행 기록에서 관리한다.

## 이유와 범위

직원 업무를 보거나 엘리베이터를 이용한 뒤 매번 재개해야 하는 흐름을 고친다. 보고·층 선택 창은 열린 동안만 배경 이동을 막고 수동 일시정지 상태를 바꾸지 않는다. 보고 창에 Esc 닫기 안내를 표시하며 Esc는 보고 창만 닫고 기존 전체 보기를 유지한다. Esc·닫기 버튼·보고 Enter 완료 후 지도 포커스를 복구하고 이전에 걷고 있었다면 자동으로 이동 가능한 상태로 돌아간다. 층 이동 성공 뒤에도 이동을 계속하고 실패하면 선택 창과 오류 안내를 유지한다.

직원 보고는 화면 중앙의 큰 모달로 확장해 현재 업무와 기록을 읽기 쉽게 한다. 데스크톱은 폭 960px 기준으로 화면 가장자리에서 16px 이상 간격을 두고 모바일에서도 화면 안에 맞춘다. 최대 높이 85dvh 안에서 긴 내용을 스크롤하며 모바일은 화면 높이에서 32px을 뺀 값도 상한으로 적용한다. 주요 본문·제목은 데스크톱 20px·24px, 모바일 18px·22px다. 어두운 배경·이름 있는 dialog/모달 상태·지역 Tab 포커스 순환을 제공하며 배경 클릭으로 닫지 않는다. Esc 보고만 닫기·Enter 보고 순환·자동 이동 복귀는 유지한다.

Space·일시정지 버튼의 명시적 수동 정지와 결재로 인한 정지는 보존한다. 전체 보기 안의 창 닫기는 전체 보기를 유지하고 부서 바로가기는 변경하지 않는다. 서버·API·DB·의존성·공통 디자인 원칙 변경은 없다. 완료된 변경 003·004는 당시 결과로 보존한다.

## 구현과 검증

- 구현 완료: 보고·층 선택 창의 열기/닫기로 수동 정지 상태를 변경하지 않고 창 상태로만 이동 차단.
- 구현 완료: 중앙의 큰 보고 모달·배경 차단·본문 스크롤·지역 포커스 순환과 기존 Esc·Enter·자동 이동 복귀 보존.
- 자동 검증: Esc·닫기·Enter 완료 후 지도 포커스·이동 복귀, 층 이동 성공 후 이동과 실패 시 창 유지, 전체 보기 보존, 수동 정지·결재 정지 보존.

중앙 모달의 기존 위치 오프셋을 해제하고 모바일 높이 경계와 계산된 스타일을 확인하는 회귀 검사를 추가했다.

중앙 보고 모달과 연속 탐색을 포함한 최종 전체 16개 파일·105개 테스트 통과. 리더가 `npm run typecheck`, `npm run build`, 설치된 원본 basic-team을 인자로 지정한 golden 비교와 `git diff --check` 통과를 확인했다. 실제 브라우저·독립 리뷰 결과는 별도 실행 기록에서 관리하며 완료를 선행 주장하지 않는다.
