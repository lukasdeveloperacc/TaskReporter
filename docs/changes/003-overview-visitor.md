# 003 — 전체 보기 탐색과 직원 업무 기록·단축키

상태: 완료. 구현·자동 검증·실제 브라우저 검증 완료. 최종 독립 리뷰 판정은 별도 실행 기록에서 관리한다.

## 이유와 범위

사용자가 전체 보기에서도 대표를 움직여 사무실을 둘러보고 직원의 현재 업무·실제 작업 기록을 키보드로 확인하도록 한다. 기존 전체 보기 진입 시 이동 일시정지·조작 숨김 규칙을 대체한다. 완료된 [변경 기록 002](002-keyboard-visitor.md)는 당시 결과로 보존한다.

전체 지도를 조작 영역을 제외한 실제 남은 지도 공간에 맞춘 채 방향키·WASD·화면 방향 버튼으로 이동하고 E·Enter·살펴보기로 실제 직원 상세와 엘리베이터를 연다. 일시정지·재개 컨트롤을 제공하고 전체 보기에서는 카메라 추적을 하지 않는다. 활성화 시 지도 포커스를 주고 상호작용 요소를 제외한 지도 배경 클릭으로 포커스를 복구한다. 방문 패널·결재 중에는 이동·상호작용을 차단한다. 방문 패널에서 Esc를 누르면 해당 패널만 닫고 전체 보기를 유지하며 패널이 없는 전체 보기의 Esc는 전체 보기를 닫는다.

직원 근처 J로 같은 프로젝트의 실제 run에서 정확히 같은 owner의 작업 기록을 연다. 현재·활성·종료·보관 run의 모든 해당 작업과 완료 작업도 포함하고 유효한 최근 보고·종료 시각 중 최신 값을 기준으로 run을 정렬한다. 현재 업무는 선택한 run에서 정확히 같은 owner의 진행중 작업만 표시한다. 직원 헤더의 owner·부서·상태는 유지한다. 저장된 제목·id·상태·note·model·effort·시작·종료 시각을 사용하고 경과 시간은 유효한 시작·종료 또는 현재 시각으로 계산한다. 계산할 수 없으면 미보고로 표시한다. 터미널 로그나 보고되지 않은 이력을 만들지 않는다. 직원 패널에서 R은 현재 업무, J는 기록으로 전환하며 접근 가능한 키보드 탭도 제공한다. 좌우 방향키·Home·End로 탭을 전환하며 R·J는 한글 자판의 물리 키로도 동작한다. 지도에 포커스가 있을 때 F로 전체 보기, Space로 일시정지·재개한다. 입력 가능 요소·수정 키·조합 입력·반복 동작 키를 무시하고 눈에 보이는 단축키 도움말을 제공한다.

기존 일반 보기·충돌 계산·실제 프로젝트 경로와 보고 데이터·결재 경계를 유지한다. 서버·DB·API·의존성·디자인 원칙 변경은 범위 밖이다.

## 검증 방법과 결과

자동 검증: 전체 16개 파일·100개 테스트 통과. 전체 보기 이동·상호작용·카메라 추적 중지·포커스·Esc·결재 차단과 직원 보고의 정확한 owner·프로젝트 경계·현재 업무·기록·탭·입력 예외를 검증했다. 직원이 실시간으로 사라지거나 run이 종료되어 선택 탭이 없어질 때 닫기 버튼으로 포커스를 복구하는 두 회귀 테스트도 통과했다. 리더가 `npm run typecheck`, `npm run build`, 원본 progress.py golden 비교와 `git diff --check` 통과를 확인했다.

실제 브라우저 검증: 격리된 localhost:4781 환경의 1440×900과 390×844에서 전체 보기를 먼저 연 뒤 둘러보기를 활성화하고 방향키·WASD로 대표가 이동하는 것을 확인했다. 두 크기에서 10개 부서가 화면 안에 맞고 카메라 스크롤은 0을 유지했다. E로 실제 엘리베이터를 열고 Esc로 패널만 닫은 뒤 전체 보기·지도 포커스·일시정지를 유지했으며 Space로 명시적으로 재개했다.

직원까지 67회 실제 키 이동 후 J로 별도 run의 완료 작업 HISTORY-ALPHA·실제 note·gpt-6-luna/max를 확인했다. R은 선택 run의 LIVE·gpt-6.1-sol/high를 표시하고 해당 과거 작업을 제외했다. R·좌우 방향키 탭 전환과 포커스, 패널 안 이동 키 차단, F 보기 전환·위치 유지, 모바일 기록 패널의 키보드 스크롤을 확인했다. 실제 결재 창에서 방향키·F가 대표를 움직이지 않았고 Space는 포커스된 결재 선택지를 정상 활성화했다. 상세 증거는 `.omc/plans/overview-report-e2e-r1.md`와 해당 화면 캡처·DOM 기록에 있다.

검증 한계: 네이티브 키 길게 누르기, 전체 프로젝트 간 기록 격리 조합, 결재 포커스·resize와 층 이동 전체 조합을 이번 브라우저 검증에서 모두 반복하지 않았다. 프로젝트·owner 격리와 실시간 직원 소실·run 종료 포커스는 자동 테스트로 확인했다. R1 브라우저 결과 이후 포커스 복구를 보강했으며 최종 독립 리뷰 완료를 이 기록에서 선행 주장하지 않는다.
