# 작업 재개 시 숨긴 층 자동 복원

상태: 완료

숨긴 프로젝트를 재사용할 때 직접 복원해야 하는 문제를 해결한다. [숨김 요구사항](../requirements/progress-office.md#building-층-숨김복원)의 기존 유지 정책을 변경한다. 종료되지 않은 작업의 report가 성공하면 기존 run·새 run 모두 같은 트랜잭션에서 숨김을 해제한다. 종료 기록만 갱신하거나 보고가 실패하면 숨김을 유지한다. 서버 재시작이나 단순 조회로는 복원하지 않는다. 기존 기록·질문·답변을 보존하고 기존 SSE로 로비와 엘리베이터를 갱신한다. 따라서 진행 중인 프로젝트를 다시 숨겨도 다음 진행 report가 오면 표시된다.

검증: MCP/HTTP 통합 25개 테스트 통과. 기존 run 보고·새 run 생성 복원, 종료 기록 갱신의 숨김 유지, 잘못된 완료 보고 후 숨김 보존, 종료 run 재개와 질문/기록 보존 확인. 실행 중 컨테이너 갱신·실제 브라우저 검증은 수행하지 않았다.
