# 006 — 복도·출입문과 위치 안내

상태: 구현·자동 검증 및 2026-10-20 R1 실제 브라우저 검증 완료. R1 E2E·Impeccable 리뷰는 PASS이며 R1 코드 리뷰의 필수 보강 3건을 아래 기록한다. 수정 후 최종 동일본 검토는 실행 진행 기록에서 관리한다. 이 문서는 승인된 복도·출입문 탐색 계약과 라운드별 확인 결과를 기록한다.

## 이유와 범위

일반 보기는 복도 → 문 가까이에서 Enter → 해당 팀 방 하나 → 출구에서 Enter → 같은 문 바깥 복도 흐름으로 바꾼다. 문 틈은 걷기만으로 넘지 못한다. 복도에서는 닫힌 방 외관·문·팀 방향 표지·엘리베이터를 보고, 내부에서는 현재 방의 실제 직원·책상·말풍선·서류·도장·결재와 출구만 본다. 기존 전역 좌표·부서 배치·직원 데이터를 공유한다.

현재 위치 이름과 실제 문 위치를 기준으로 한 팀 방향 표지, 실제 대표 위치·현재 방·안내 목적지를 보여주는 작은 미니맵을 제공한다. 일반 보기의 부서 바로가기는 안내 목적지만 정하며 대표 이동·일시정지를 바꾸지 않는다. 미니맵은 클릭 이동 없이 위치를 안내한다. 모바일에서도 위치 안내와 조작부가 보이게 한다.

전체 보기는 기존 열 개 방·실제 직원의 전체 지도와 이동·상호작용·부서 바로가기 스크롤을 유지한다. F 전환은 대표 위치를 보존하고 일반 보기 복귀 시 실제 좌표로 방 또는 복도를 결정한다. 전체 보기의 기존 벽·문 틈 이동 규칙은 유지한다.

유효한 층은 직접 URL 로딩·로비 진입·다른 층 이동 시 별도 활성화 클릭 없이 둘러보기를 시작한다. 초기 로딩 중에는 시작 의도를 지우지 않는다. 명시적 끝내기는 같은 run의 보고 갱신에도 유지하며 다른 유효 층 진입·로비 재진입 또는 직접 재시작 때 활성화한다. 로비·로딩이 끝난 잘못된 경로에서는 종료한다.

직원 보고 Enter 현재 업무 → 기록 → 닫기, Esc 후 이전 걷기 상태와 지도 포커스 복귀, 엘리베이터 탐색, 명시적 일시정지·결재 포커스 경계는 유지한다. 일반 보기에서는 가까운 문을 우선하고 현재 방 직원 또는 복도 엘리베이터만 상호작용한다. 서버·API·DB·의존성 변경은 없다. 변경 002~005는 당시 결과로 보존한다.

## 검증 계획과 결과

- 모든 열 개 문: 복도 접근, 문 틈 걷기 차단, Enter 입장·퇴장, 하단 임시 방 포함 지도 경계 안의 왕복 위치.
- 일반 보기: 현재 방만 표시·상호작용, 문 입력 반복·패널·결재 차단, 보고·엘리베이터·수동 정지 회귀 검사.
- 활성화: 지연된 직접 URL 로딩, 로비 재진입, 끝내기 후 같은 run 보고 갱신.
- 위치 안내: 실제 좌표와 방향·미니맵 일치, 전체 보기 위치 보존과 일반 보기 복귀.
- 실제 브라우저: 데스크톱 1440×900·모바일 390×844에서 복도 → 문 Enter → 직원 보고 → Esc → 출구 Enter → 복도, 전체 보기와 가로 넘침·포커스 확인.
- 최종 검사: 전체 테스트·typecheck·build·원본 basic-team golden 비교·diff 검사와 동일 변경본의 Karpathy·Ponytail·Impeccable·E2E 독립 리뷰.

리더가 전체 자동 검사 결과를 확인했다. `npm test`는 18개 파일·118개 테스트를 통과했으며 `npm run typecheck`, `npm run build`, 설치된 원본 basic-team을 인자로 지정한 golden 비교, `git diff --check`도 통과했다. 이 수치는 R1 보강 전 검사 결과다.


### 2026-10-20 R1 실제 브라우저·리뷰

E2E Agent는 데스크톱 1440×900과 모바일 390×844의 실제 입력으로 복도 → 문 Enter → 해당 방 → 실제 직원 현재 업무·기록 → Esc 후 즉시 걷기 → 출구 Enter → 복도를 확인하고 PASS를 판정했다. 방향 안내·미니맵 위치, F 전체 보기의 열 개 방과 위치 보존, Space 정지·재개, 엘리베이터 키보드 탐색·로비 이동·재진입, 명시적 끝내기·재시작과 모바일 가로 넘침 없음도 확인했다. 실제 결재 창 조작, 모든 문 경로의 전수 브라우저 확인, 보고를 연 동안의 실시간 메타데이터 변경은 이 브라우저 검증 범위에 포함하지 않았다. 근거는 실행 기록 `.omc/plans/door-e2e-r1.md`다.

Impeccable Agent는 PASS를 판정했으며 문 표지와 아바타 겹침은 권고 사항으로 남겼다. Karpathy·Ponytail 코드 리뷰에서는 초기 로딩 실패 후 재시도의 활성화 의도 보존, 화면 버튼의 Enter 반복 차단, J로 기록을 열 때 문 우선순위 등 필수 보강 3건을 확인했다. 이는 R1 당시의 판정이며 수정 후 최종 동일본 검토는 실행 진행 기록에서 관리한다.


### 2026-10-20 R1 보강 완료와 최종 자동 검사

초기 로딩 실패 후 재시도의 활성화 의도 보존, 화면 버튼 Enter 반복 차단, J 기록 열기의 문 우선순위 등 필수 보강 3건을 수정 완료했다. 리더가 보강 후 전체 18개 파일·120개 테스트와 `npm run typecheck`, `npm run build`, 원본 basic-team golden 비교, `git diff --check` 통과를 확인했다. 전체 기능 구현과 R1 실제 브라우저 검증은 완료했으며 수정 후 최종 동일본 리뷰 판정은 실행 진행 기록에서 관리한다.
